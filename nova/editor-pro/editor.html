          About Narrators

          What are Narrators?
          Narrators combine a specific voice with script‑writing guidance. You give a name, pick a voice, and provide transcript examples so the AI learns how to write in that style.
          Why create them?
          They let you reuse consistent voice + writing style across videos. Great for branding, different personas, or multiple channels.
          How do I create one?
          Click Create Narrator, enter a name, pick a voice, and add transcript text. You can paste text or import from a file or YouTube link.
          How do I use them?
          In Video Creator Step 2, switch to the Narrator tab to pick one. This controls both the voice and the script style.

          How to Use the Advanced Editor

          Start with the basics, then explore planning, audio, and exporting for best results.

          Basics

          • Set your Video Title at the top.
          • Open the File menu to Add Page and Add Files.
          • Use Total Duration and Min/Max Clip Length in the Inspector to control pacing.
          • Toggle Mute globally, or per section, to get clean BGM/voice mixes.
          • Use the toolbar layout toggles (☰ / ▤ / ☷) to collapse or expand the left sidebar, preview area, and right sidebar to focus on Planned clips.

          Pages

          • Use Add Page to create structure: e.g., Hook, Body, Ending.
          • Each page can hold videos and images; Shuffle determines randomization within the page.
          • Set the End time on each page to precisely allocate the total duration.
          • Enable Mute per page if you plan to add voiceover or BGM.

          Planning Clips

          • Click Preview Plan to generate a clip plan from your selected files.
          • Toggle between Grid and List views in the Planned clips header. List view adds a mini‑viewer on the right and shows actions inline.
          • In either view, use the checkbox to include/exclude clips. In list view, press Play on a row to preview that segment in the mini‑viewer.
          • When a Voiceover is added, list view playback syncs the VO to the clip's start time for quick alignment checks.
          • Enable Autoplay under the mini‑viewer to automatically advance through included clips; the current row is highlighted.
          • Use Refresh on a clip to fetch a different segment from the same sources.
          • Adjust Inspector settings and re‑preview to iterate until pacing feels right.

          Preview

          • Preview Plan builds a merged preview you can immediately watch in the player.
          • Use the big Play/Pause button below the player and scrub with the timeline slider to navigate.
          • Play in Viewer plays your planned clips sequentially in the main player (best for video‑only plans).
          • Switch between merged and sequential preview depending on whether images are included. If images are present, merged preview is recommended.

          Audio & Voice

          • Add BGM and Voiceover in the Inspector panel.
          • Adjust BGM Volume, Voice Volume, and Duck for clarity.
          • Use Preview Mix to hear audio before exporting.
          • Voiceover aligns where pages have Mute enabled.

          Export

          • Choose Save To… from the File menu to set an output folder.
          • Click Export to render the final video with your plan and settings.
          • After export, use Play Video or Show in Folder (main screen) to view the result.

          Projects

          • Use Open Project and Save Project to manage work‑in‑progress.
          • Autosave periodically writes to an autosave file if a save location is set.
          • Close Project resets the editor to defaults.

          Tips

          • Use multiple pages to enforce narrative order while keeping variety within each section.
          • Shorten Max Clip Length for faster pacing; lengthen for calmer edits.
          • Use Include/Exclude and Refresh to curate your plan precisely.

          Advanced Editor Features

          Explore every capability with clear explanations and practical examples.

          Pages

          • What it is: Logical groups of files (videos/images) that shuffle internally, merged in order.
          • Why it matters: Lets you keep narrative structure (Hook → Body → Ending) while maintaining variety.
          • How: File → Add Page, then Add Files. Use Shuffle toggle per page.
          • Example: Page 1 (hook b-roll), Page 2 (topic visuals), Page 3 (call‑to‑action assets).

          Planning Clips

          • What it is: The app proposes clip segments from your sources using your min/max length and options.
          • Views: Switch between Grid and List in the Planned clips header. List view adds a mini‑viewer and inline actions.
          • Mini‑viewer: Press Play on a row to preview that segment; if a Voiceover is added, the VO starts at the same timecode as the clip.
          • Autoplay: Enable under the mini‑viewer to advance through included clips automatically; the current row is highlighted.
          • Include/Exclude: Uncheck to drop a segment from the final plan.
          • Refresh: Replace a segment in place to find a better moment.
          • Example: Set 3–5s clips, run Preview Plan, exclude pauses, refresh to swap shaky picks.

          Per‑Page End Times

          • What it is: A precise time budget for where each page ends within the total duration.
          • Why: Guarantees pacing—no single page overruns the plan.
          • How: Edit the End field per page; the last page auto‑fills total.
          • Example: 10:00 total → Hook ends 0:30, Body ends 9:30, Ending ends 10:00.

          Audio & Voice

          • BGM: Add multiple tracks; order matters. Adjust BGM Volume.
          • Voiceover: Add a single voice track; adjust Voice Volume.
          • Ducking: Lower BGM under voice for clarity.
          • Alignment: Voiceover aligns where a section has Mute enabled.
          • Example: Mute pages with narration, keep ambient in b‑roll pages.

          Preview Modes

          • Merged Preview: Builds a quick composite video; recommended when images are used.
          • Sequential Playback: Plays segments in order using the player; best for video‑only plans.
          • Controls: Use the main Play/Pause button and scrubber to navigate; use the toolbar layout toggles (☰ / ▤ / ☷) to maximize viewing area.
          • Example: Include images → use Merged. All video → try Sequential for quick scrubbing.

          Export

          • Save To…: Set your output folder first (File menu).
          • Export: Renders the final video with current plan, section end times, and audio mix.
          • Example: Finalize includes/excludes, preview, then Export to MP4 and review.

          Projects

          • Open/Save: Manage work‑in‑progress with JSON project files.
          • Autosave: Writes periodically if a save location is set.
          • Example: Save before Export to preserve your curated plan and section times.

          Files & Locations

          • Open Clips Location: Quickly opens the temporary clips folder used for planned/preview clips.
          • Where they live: By default, clips are saved in your system temporary folder during planning/preview.
          • Tip: Set Save To… before export to control where final outputs land; temp clips remain in the system temp folder.

          Workflows

          Short, practical flows for different creators and toolchains.

          Workflow A — Advanced Editor (from docs)

          1. Find your video idea.
          2. Create a script.
          3. Create a voiceover using whatever tool you want.
          4. Open the Advanced Editor and create a project.
          5. Add the voiceover to see how long it is and have it ready for export.
          6. Add your video clips and images to the timeline.
          7. Preview the video.
          8. Export and upload to YouTube.

          Workflow B — Nova + Premiere Pro

          1. Import source footage into Nova; create Pages (Hook/Body/Outro).
          2. Enable Mute only on VO pages; keep on‑camera audio elsewhere.
          3. Use Preview Plan, exclude weak clips, refresh where needed.
          4. Export an MP4 and bring it into Premiere.
          5. In Premiere, add titles, color, transitions, and sound design as desired.
          6. Render final deliverable; keep your Nova project JSON for future versions.

          Workflow C — Shorts from long videos

          1. Select 1–3 long recordings; set Min/Max to 1.5–3s and Total to 45–60s.
          2. Enable Auto‑detect cuts and Review before merge.
          3. Use Pages to allocate time: Hook (10–15s), Body (25–40s), Outro (5–10s).
          4. Preview, exclude filler, refresh shaky picks, then Export.
          5. Upload to Shorts/Reels/TikTok; iterate with new seeds for variants.

          Workflow D — Research → Production

          1. Use Niche Finder to find formats that outperform baseline.
          2. Collect reference links with the Chrome extension; copy URLs.
          3. Draft a script with Script Shufflr (or your own doc).
          4. Create Pages to match your format; add BGM/VO if needed.
          5. Preview plan, curate, then Export to MP4.

          Workflow E — Podcast/Audio highlights (images + VO)

          1. Add still images/screenshots; Nova auto‑converts them into motion clips.
          2. Add your voiceover; set Total to match VO length.
          3. Enable Mute on all pages so VO plays cleanly.
          4. Add BGM at ~20–30% and enable Duck.
          5. Preview mix and video; export for YouTube/Spotify video.

          Workflow F — Multi‑cut client delivery

          1. Create a base project; save as JSON.
          2. Duplicate the project file; adjust Total and Min/Max for Alt A/B/C.
          3. Refresh subsets of clips to create distinct but on‑brand variants.
          4. Export multiple MP4s; name with version tags (vA/vB/vC) for review.
          5. Share with client; keep the best performing version as a template.

          Quick Editing Tips

          Fast, practical ways to get a solid cut quickly.

          Core Tips

          • Sometimes downloaded clips aren't usable. Delete unusable videos and duplicate the usable ones to keep momentum.
          • Drag and add files to different pages. Duplicate and repeat to get the best outcome and avoid "ending/subscribe" clips showing up mid‑video.
          • Use the Planned clips area (bottom middle) to fine‑tune before export. Toggle between Grid and List view to dial in exact segments.
          • Exclude weak segments with the checkbox, then use Refresh to swap for a better moment from the same source.
          • Keep clips short for energy: try Min 2s, Max 4s on fast formats; lengthen for calmer edits.
          • Put "subscribe/outro" assets in the last section so they only appear at the end.
          • If you want a fast‑paced video with more planned clips to review, set Min to 1s and Max to 3s. This creates unique videos fast and may require a bit more curation. For slower‑paced videos, set Min 3s and Max 6s. Going over 7s isn't advised unless you have originally produced content.

          Speed Moves

          • Set Total Duration first, then add pages—your End times will align faster.
          • Enable Auto‑detect cuts on jump‑cut heavy footage to get better proposed segments.
          • Use Play in Viewer for rapid sequential checks; switch to merged Preview if images are included.
          • Turn on Autoplay in List view to fly through included clips while you curate.

          Audio & Export

          • For voiceover, enable Mute on VO pages for clean narration.
          • Duck BGM under voice for clarity; aim for ~20–30% BGM volume as a starting point.
          • Do a quick Preview Mix before exporting.
